# פרק 10 – סטטוס בסוף סמסטר א' ותוכנית לסמסטר ב'

## 10.1 תוצרים שהושלמו בסמסטר א' (ספרינטים S1 עד S5)

בסמסטר א' הושלם שלב האפיון והתכן, ונבנה אב-טיפוס להוכחת ההיתכנות הטכנולוגית. התוצרים מאפשרים להתחיל את המימוש בספרינט S6 בלי פתיחה מחדש של החלטות תכן.

**טבלה 10.1 – תוצרי סמסטר א'**

| תוצר | תכולה | מיקום |
| --- | --- | --- |
| מסמך האפיון | פרקים 1 עד 10, ביבליוגרפיה ונספחים | מסמך זה; `docs/` במאגר |
| דיאגרמת Use Case | 3 שחקנים ו-20 מקרי שימוש, כולל קשרי «include» ו-«extend» | איור 3.1; `FitVision_UseCase.drawio` |
| DFD | רמה 0 (דיאגרמת הקשר) ורמה 1: 7 תהליכים, 6 מאגרים ו-24 זרימות | איורים 4.2 ו-4.3; `FitVision_DFD.drawio` |
| ERD | 17 טבלאות מנורמלות, כולל `Users.consent_at` ו-`TrainerProfiles.invite_code` | איור 4.4; `FitVision_ERD.drawio` |
| Wireframes | 5 מסכים: 3 מסכי מתאמן בטלפון ו-2 מסכי מאמן במחשב | איורים 5.2 עד 5.4; `FitVision_Wireframes.drawio` |
| הוכחת היתכנות (T-03) | אפליקציית ווב שמפעילה מצלמה, מריצה MediaPipe Pose ב-Web Worker, מחשבת את זווית הברך וסופרת חזרות בסקוואט | נספח ג'; `poc/` במאגר |
| תשתית ניהול | מאגר GitHub, Product Backlog של 113 SP ותוכנית ספרינטים | פרק 7 |

**הוכחת ההיתכנות.** ה-PoC בודק את ההנחה הטכנולוגית המרכזית: אפשר לזהות שלד בדפדפן הטלפון בקצב שמספיק למשוב בזמן אמת, בלי לשלוח וידאו לשרת. האב-טיפוס מממש את שלבים 1 ו-2 של האלגוריתם (סעיף 4.6), ונכללות בו שתי פעולות המניעה לסיכון R-01: הרצה ב-Web Worker ומעבר אוטומטי למודל Lite. הלוגיקה של חישוב הזווית, ההחלקה ומכונת המצבים נבדקה ב-8 בדיקות יחידה. מדידות ה-FPS וההשהיה בטלפון מתועדות בטבלה ג.2 בנספח ג'.

## 10.3 תוכנית המימוש לסמסטר ב' ומוכנות לסקר האמצע

סמסטר ב' של שנה"ל תשפ"ח (מרץ עד יוני 2028) מוקדש למימוש, לבדיקות ולפיילוט, בחמישה ספרינטים (S6 עד S10, טבלה 7.5). כל פריטי ה-Must מתוכננים עד ספרינט S9. ספרינט S10 מוקדש לפיילוט ולפריטי Should ו-Could, שאותם אפשר לדחות אם הקצב נמוך מהמתוכנן (R-07).

**מוכנות לסקר האמצע.** סקר האמצע מתקיים בשבוע הראשון של סמסטר ב' (משוער: 9/3/2028). הצוות יציג בו:

1. את מסמך האפיון המאושר ואת ההערות שהתקבלו עליו.
2. הדגמה חיה של ה-PoC בטלפון, עם מדדי ה-FPS וההשהיה שנמדדו.
3. תוכנית ספרינטים מעודכנת ל-S6 עד S10, עם הקצב שנקבע לאחר תכנון ספרינט S6.
4. את סטטוס הסיכונים (טבלה 8.1) ואת השינויים שחלו בו מאז סוף סמסטר א'.
5. את ההתקדמות בספרינט S6: סביבת CI, מסד נתונים ב-Docker ו-17 הטבלאות בהגירות Alembic.

**תוצרי הסיום לקראת כנס הפרויקטים**

- **קוד מקור** – מאגר GitHub מלא, עם היסטוריית Pull Requests ובדיקות אוטומטיות שעוברות.
- **מערכת מותקנת** – שרת FastAPI ו-SQL Server במיכלי Docker, ואפליקציית PWA נגישה בכתובת HTTPS.
- **תיק תחזוקה** – הוראות התקנה והפעלה, מפרט API (נספח א' בגרסה מלאה דרך Swagger), תיאור הסכמה והגירות, והוראות להוספת תרגיל דרך TechniqueRules.
- **סיכום הטמעה** – תוצאות הפיילוט, מדדי ההצלחה מול טבלה 9.2, לקחים והמלצות להמשך.
- **פוסטר ומצגת** – לכנס הפרויקטים, כולל הדגמה חיה של אימון ודוח מאמן.
